2. AIGC language-model detector
-------------------------------
Files:
  aigc/detector.py
  aigc/segscore.py
  aigc/segdiag.py

Model identifier: yuchuantian/AIGC_detector_zhv3
Model source: https://huggingface.co/yuchuantian/AIGC_detector_zhv3
Model license: Apache-2.0
Base model: chinese-roberta-wwm-ext (Apache-2.0)

Model weights are NOT distributed with this repository. Only the model id is
referenced. Weights are downloaded by the user from HuggingFace on first
calibration. Runtime dependencies (torch, transformers) are installed by the
user and are not bundled.
